# 🎬 AHL Viral Script Engine — Content Writer Guide

> **Who this is for:** New content writers at American Hairline (AHL).
> **What this teaches:** How to use the Viral Script Engine web app to go from a topic idea to a fully production-ready Instagram Reel script.
> **Read this once. Then you'll know everything.**

---

## What Is This System?

The **Viral Script Engine** is a custom AI-powered web app built specifically for American Hairline. It helps content writers:

1. **Generate topic ideas** for Instagram Reels targeting AHL's ideal audience
2. **Brainstorm angles** with an AI strategist
3. **Get Sir's (Vinitt's) opinion** on the angle
4. **Generate a complete, production-ready Reel script** in AHL's exact brand voice
5. **Revise the script** based on Sir's feedback
6. **Generate hooks** (verbal, visual, action, text-on-screen) once the script is approved

Everything is saved automatically to a shared Google Sheets database — so the whole team sees the same data in real time.

---

## The Big Picture: How a Script Gets Made

Here is the complete journey, from idea to final script:

```
IDEA → ANGLE → SIR'S OPINION → SCRIPT → REVISIONS → HOOKS → DONE ✅
```

Each step below maps to a tab or section inside the app.

---

## Step 1 — Generate or Add a Topic

**Go to: ⚡ New Ideas tab**

- Click **"⚡ Generate New Ideas"** — the AI will suggest 10 high-engagement reel topics specifically for AHL's audience (people actively considering a transplant or hair system).
- Click **"Add →"** next to any idea you like. It becomes a "topic card" on the Board.
- Or type your own topic in the **"custom topic"** field at the bottom and click **Add Topic**.

> 💡 **Tip:** You can add a **Target Audience** when adding topics. Use the dropdown to pick a specific audience profile (e.g., "Men 25-40 considering transplant"). This tailors the angles and script for that audience.

---

## Step 2 — Discuss the Angle (Chat with AI)

**Go to: Your topic card → 💬 Discuss tab**

When you open a topic, the AI automatically suggests **5 tailored angles**. Pick one by clicking **"Use Angle →"**, or type your own angle in the chat box.

Once an angle is selected, you can chat freely with the AI:
- Refine the angle ("make it more controversial")
- Ask for story ideas ("what real-world proof can we use?")
- Brainstorm the hook direction

> ⚠️ **Important:** The AI in chat mode is a **content strategist**, not the script writer. It helps you shape the angle. The actual script is generated in a separate step.

---

## Step 3 — Send the Brief to Sir

**Go to: 💬 Discuss tab → Click "📋 Copy Brief for Sir"**

Once you're happy with the angle discussion, click **"📋 Copy Brief for Sir"**. This:
- Copies the full discussion as a clean formatted brief
- Marks the topic as **"Waiting for Sir"** on the board

Paste the copied text in WhatsApp and send it to Sir (Vinitt). Wait for his feedback.

---

## Step 4 — Add Sir's Opinion

**Go to: Your topic card → 🎙️ Sir's Opinion tab**

Sir gives his feedback in one of two ways:

### Option A — Sir sends a voice note
1. Download the voice note from WhatsApp
2. Click the upload zone (🎙️) in the app
3. The system auto-transcribes it using **Whisper AI** (it handles Hindi, Marathi, and English mixed speech perfectly)
4. The text appears automatically

### Option B — Sir replies with text
- Simply paste his reply directly into the text area

> After adding Sir's feedback, the topic status changes to **"Sir's Opinion In"**.

---

## Step 5 — Generate the Script

**Go to: 🎙️ Sir's Opinion tab → Click "✨ Generate Script"**

Once Sir's feedback is added, click **"✨ Generate Script"**.

The AI runs **two internal passes**:
1. **Draft pass** — generates a full script using Sir's brief + AHL's brand rules
2. **Audit pass** — the AI critiques its own draft and rewrites it to 10/10

This is exactly how Sir works: "never one-shot, always audit to 10/10." You always see the final 10/10 version — not the draft.

> ⏱️ **This takes about 5–10 seconds.** A typing indicator appears during generation.

The topic status will change to **"Script Ready ✓"** and you'll be taken to the **📝 Script tab** automatically.

---

## Step 6 — Review the Script

**Go to: Your topic card → 📝 Script tab**

The generated script follows AHL's strict **7-block structure** (see below for details). Review it top to bottom.

You can:
- **📋 Copy** the script to share it
- Click **"✅ Approve & Generate Hooks"** if it's ready
- Or go to the revision section below if Sir has changes

---

## Step 7 — Revise the Script (if Sir has feedback)

**Go to: 📝 Script tab → Scroll down to the revision section**

If Sir reviews the script and has notes:
1. Upload his voice note **or** paste his text feedback in the revision box
2. Click **"Revise Script"**
3. A new version is generated (v2, v3, etc.)
4. You can switch between versions using the version buttons at the top

> 🧠 **Auto-Learning:** Every time Sir gives feedback, the system automatically learns his preferences and updates **"Sir's Style Guide"** in the background. Future scripts will automatically apply these rules without you doing anything.

---

## Step 8 — Generate Hooks

**Go to: 📝 Script tab → Click "✅ Approve & Generate Hooks" → then 🪝 Hooks tab**

Once the script is approved, generate 6 hook variations:
- **3 Verbal Hooks** — what the person says directly to camera
- **1 Visual Hook** — a striking visual element or prop
- **1 Action Hook** — a specific action or movement
- **1 Text-on-Screen Hook** — a compelling text overlay

Pick the best one and mark it as the selected hook for production.

## Understanding AHL's Script Format

Every generated script follows this **7-block structure**:

| Block | What It Does |
|---|---|
| `[HOOK]` | First 1-3 words stop the scroll. Bold text overlay + one voiceover line. They say different things. |
| `[THE TURN]` | Hard cut to the problem. A beat of silence. |
| `[TRUTH BOMB]` | Full screen graphic. White text, black background. 3-5 seconds of silence. The single most shareable fact. |
| `[AUTHORITY]` | Direct to camera. Sir's personal proof. Cold and short. |
| `[HARD TRUTH]` | Three escalating beats. Each one hits harder. |
| `[CTA]` | One clean sentence. Comment CLIP, Share with someone, etc. |
| `[CLOSE]` | Purely visual. White text on black, word-by-word reveal. No voiceover. Ends with AHL logo. |

> **Target duration: 40–50 seconds.** The script always ends with `Runtime: ~XX sec`.

## Key Brand Rules (Know These)

### 1. The First Word Rule
If the topic involves a celebrity — the celebrity's name MUST be the first word.
- ❌ `"So you can see the hair Virat wears..."`
- ✅ `"Virat Kohli's hair..."`

### 2. MOFU / BOFU Only
Scripts target people **seriously considering** a transplant or hair system. Not general audiences, not beginners.
- **MOFU** = Middle of Funnel (actively considering)
- **BOFU** = Bottom of Funnel (ready to decide)

### 3. Hemingway Rule
Every line must be readable by a 10th-standard student. No medical jargon.
- ❌ `"DHT blockers prevent follicular miniaturization"`
- ✅ `"Yeh baal ki jad ko marne se rokta hai. Bas."`

### 4. Language Mode (Default: Hinglish)
Three modes: `english` / `hindi` / `hinglish`.
- **Hinglish** = 50/50 at the **thought level** — never mid-sentence
- ✅ `"Yeh science hai. Baaki sab marketing hai."` ← correct (thought level)
- ❌ `"Yeh science hai, but marketing isn't."` ← wrong (mid-sentence mix)

### 5. Never One-Shot
The system always runs two passes. You will never see a draft. You always see the 10/10 audited version.

## Common Questions

**Q: What if the script doesn't feel like Sir's voice?**
The style gets better over time. Every time Sir gives revision feedback, the system learns. After a few scripts, the AI starts nailing Sir's preferences automatically. Also check **🧠 Sir's Style Guide** — if a rule is missing, you can add it manually.

**Q: Can I run multiple topics at the same time?**
Yes. Add as many topics as you want. Each one is completely independent — they don't interfere with each other.

**Q: What audio formats does transcription support?**
MP3, OGG, M4A, WAV, WEBM. Any standard voice note format. Max 50 MB.

**Q: What if I accidentally send the wrong topic to Sir?**
You can reset a topic's status by editing it on the board. Or just delete the card and start fresh — use the **🗑 Clear All** button (with caution, this deletes everything).

**Q: The app says "Syncing with Database" on load — is that normal?**
Yes. The app pulls all data from a shared Google Sheets database on startup. This takes 1–2 seconds. Don't refresh while it's loading.

**Q: What if I want to write a script in pure English or pure Hindi?**
Mention the language in your angle discussion or in Sir's feedback. The AI will switch modes. You can say "write this in English only" or "full Hindi please."
